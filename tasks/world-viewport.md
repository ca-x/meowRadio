# v0.4.1 viewport exploration

User-confirmed rules: list must paginate, selectable 24/100/500/1000; globe/nebula have no UI pagination, keep filters, cover the whole world when unfiltered. Only current viewport points/countries/genres need detail/rendering. Zoomed-out country/genre clusters represent the full directory; zooming/clicking loads visible details. Do not await a complete remote station dump before the map is usable. Real Radio Browser defaults to 1000 and bulk requests are slow; directory facets are the lightweight global index.

Contract:
- Station gains optional cluster: {kind: "country"|"genre", key: string, count: number|null}. Cluster is never playable, recordable or favoritable. Globe country centroids come from bundled map geometry; nebula genre clusters use real directory tags.
- GET /api/stations/explore keeps existing filters and adds view=globe|nebula, countries=comma-separated visible codes (max12), genres=visible raw tag keys including * remainder (max12), detail=integer level (0 overview, >0 visible detail). Returns {items: Station[], total: number|null, complete: boolean}. The complete flag describes detail completeness; unreturned stations remain represented by cluster nodes, never silently excluded by a fixed page cap.
- Unfiltered overview responds with every directory country/available genre cluster quickly. Detail requests only address explicit/visible countries (or selected genre), cache/coalesce them. Clicking a cluster focuses/zooms and increases detail. Keep aggregate remainder when details are partial. Count unknown rather than invent counts for combined filters.
- Renderer accepts optional clusters via Station, culls back hemisphere/frustum before GPU submission, emits visibility after camera settles (not React state every frame). Visibility: {ids:string[],countries:string[],genreCounts:number[],distance:number,cameraKey:string}. Genre filter changes indices, not renderer creation. Cluster click invokes onChoose, which App intercepts to drill down rather than play.
- World UI limits selector/filter facets to visibility; country/genre counts reflect visible content, clusters identified as aggregates. Preserve audio, camera during detail updates, filters, keyboard/accessibility, reduced motion and context loss recovery.

Ownership: backend implementer owns src/exploration.rs, src/catalog.rs, tests/exploration.rs; renderer implementer owns StationScene.ts, StationWorld.tsx and their scoped tests/spatial helpers as coordinated; root owns App.tsx, api.ts, StationFilters, styles/i18n, list/private pagination, integration, docs/release. Root alone commits/pushes/tags. All tasks reviewed before release.
