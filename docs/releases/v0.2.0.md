阿喵收音机 v0.2.0 新增五套主题、个人录音库及账号资料管理，并支持断流自动重连。

- 九套收音机外观支持中文/英文、浅色/暗色；新增弧光调谐、奶油白、黑白刻度、银色复古、红屏像素。每套主题使用独立 CSS。
- 用户菜单统一提供个人选项、系统设置、录音管理、退出登录。个人选项只有“个人资料”和“修改密码”两个页签；系统设置加宽并区分主题与其他设置。
- 昵称、头像可修改。头像按用户名保存为 WebP 并覆盖原文件；修改密码保留当前会话、撤销其他会话。
- 服务器中转音源支持开始/停止录制。换台或停止播放自动结束并保存；个人录音库支持试听、重命名、下载和确认删除。默认文件路径为 /data/record/<用户名>/<UUID>，每条100MiB、每用户1GiB。
- 系统设置提供浏览器支持的录制格式、目标码率及最长时长。录制不请求麦克风；不支持录制API的浏览器显示限制。
- 网络中断使用递增间隔自动重连，返回前台/联网时检查恢复；手动暂停、定时截止不误恢复。系统挂起网页期间无法保证连续播放。
- 播放器中转入口改成纯图标 toggle，说明通过 tip 显示。列表中转图标只作用于本次播放，不修改默认偏好。

验证：111项前端测试、42项Rust测试通过，TypeScript、Clippy、发布构建及依赖审计通过；实际HLS录制、换台保存、库内试听和个人资料修改已实测。懒猫实机与 Safari 录制能力仍需设备侧验证。
