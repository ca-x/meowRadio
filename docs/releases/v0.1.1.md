# 阿喵收音机 v0.1.1

本版完善了收听、筛选、外观与登录体验，并使用正式的猫耳收音机 Logo。

- 四套外观均支持浅色和暗色，新增中文 / English 切换。
- 登录与注册位于独立 `/login` 页面；登录过程保留播放器和浏览条件。
- 首页只保留筛选入口，按需选择国家、语言、类型、排序、编码和音质，无需输入关键词。
- 优化中文输入法、Enter 搜索、FM 频率写法及空结果恢复。
- 增加时钟式定时关闭：拖动时针/分针，支持键盘、数字输入及快捷时长。
- 可设置关闭前 10 秒、30 秒、1 分钟或 5 分钟显示强调倒计时，也可关闭；轻度动画遵循减少动态效果设置。
- 电台提供独立代理播放入口，设置中可测试服务端代理/外网连通性及耗时。
- README 更新 PC 端三张和移动端三张实际截图。

提供 Linux amd64/arm64、macOS amd64/arm64、Windows amd64 二进制与 SHA256SUMS；Docker 支持 linux/amd64、linux/arm64：

```sh
docker run -d --name meowradio -p 3000:3000 -v meowradio-data:/data ghcr.io/ca-x/meowradio:v0.1.1
```

首次访问使用初始化向导，也可通过 `MEOW_INIT_USERNAME` 和 `MEOW_INIT_PASSWORD` 自动初始化。已有数据库可直接升级，原账号和收藏保留。

说明：配置出站代理时，音频中转暂限 HTTP 音源；HTTPS/HLS 音源可使用直连。未配置出站代理时，服务端中转支持公共 HTTP/HTTPS 连续音频流。FM 检索针对网络直播目录，不接收本地无线电信号。
