阿喵收音机 v0.1.2 修复首页导航中断播放、筛选和默认中转方式丢失，以及 HTTP HLS 无法通过服务端收听的问题。

- 首页顶栏切换中文 / English、浅色 / 暗色；设置显示版本。
- 四套收音机外观增加播放状态动效，暂停、缓冲、静音或隐藏页面时停止。
- 宣传文字淡入后停留约 1.5 秒再淡出，页面布局不跳动。
- HLS 中转支持播放列表、密钥、初始化片段、分片和字节范围；资源链接绑定登录用户与电台。
- HTTP/HTTPS/SOCKS5 代理支持公共地址固定解析；HTTP(S) 代理需允许目标端口 CONNECT。
- 仅在 LazyCat WebShell 中接入原生控制栏、媒体状态和安全区域适配。
- README 更新 PC、移动端各三张截图。

验证：52 项前端测试、30 项 Rust 测试通过；TypeScript、Clippy、生产构建和 npm 审计通过。懒猫实机与 Safari 需设备侧验证。
