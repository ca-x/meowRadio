新增个人电台源，可通过网络地址或 JSON 文件导入，并按账号独立管理。

- 首页区分系统电台与个人电台，收藏可以放在一起，个人电台会标明来源。
- 支持多条备用地址、分类路径、播放页及接口解析，以及 HTTP(S)、HLS、FLV、RTMP(S)、RTSP(S)、MMS/MMST/MMSH 音源。
- 导入、更新后逐条检查地址，对话框只列出失败线路，确认后才清理；仍有有效地址的电台和收藏会保留。
- 可删除单个电台、单个源或全部个人源，并同步移除对应收藏；管理页提供格式说明和示例下载。

个人源播放与检测需要 FFmpeg，Docker 镜像已包含；二进制部署请安装 FFmpeg，或用 `MEOW_FFMPEG` 指定路径。历史链接是否可用仍取决于上游服务状态。

验证：122 项前端测试、99 项 Rust 测试通过；浏览器验证央广实际播放、录制，以及只清理两条失败地址后保留有效线路和收藏。
